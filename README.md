# Project Template

Python project template for AI-agent-friendly development. Includes a library (core), CLI (Typer), and UI (Streamlit).

## Quick Start

```
make install-dev   # install with dev tools
make help          # see available commands
make test          # run tests
```

## Docs

- **AGENTS.md** — development rules and workflow for AI agents
- **docs/adr/** — architectural decision records (ADRs)

Read AGENTS.md before making any significant changes.
